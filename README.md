本サイトは『FINAL FANTASY XIV』のコンテンツ「モブハント」の報告・情報共有を行うためのツールです。
ユーザー間でのリアルタイムな情報共有により、効率的な探索を支援することを目的としています。

---

## 💮 キャラクター連携の必要性

本サイトでは、情報の信頼性を担保し、不適切な投稿を抑制するために、「**Lodestone認証**」を必須としています。

- **情報の信頼性**: 報告者の識別を可能にすることで、データの正確性を維持します。
- **コミュニティの保護**: 悪意のあるユーザーによるデータの改ざんや荒らし行為を防止します。

※連携手順は、「**ユーザー認証モーダル**」の案内に従ってください。
※討伐報告やマップ座標報告をする初回に認証モーダルが表示されます。1度認証を行えば、次回から表示されません。
※サーバーで管理されているのは、ロードストーンIDとキャラクター名のみです。**パスワードなどは管理していません。**

## 🧭 アプリナビ：主要機能と通知

画面のアイコンより、各パネルの表示・操作が可能です。

- **📊(RANK)**  
  モブのランク（S/A/F）や拡張パッケージ別のフィルタリングを行います。  
  1度目でランク間を切り替え、同ランクボタンを2度押すと拡張ボタンが表示されます。再度押すとボタンを閉じます。  
  初期状態はすべてのモブがONになっています。不要なものはOFFにしてください。
- **📢(告知)**  
  管理者からのお知らせを表示します。
- **🛠️(メンテ)**  
  FF14内のサーバーメンテナンス予定日時をお知らせします。
- **⚠️(エラー)**  
  システムエラーの詳細を確認できます。
- **🔔(通知)**  
  音声通知やブラウザ通知の有効・無効を切り替えます。

  - **タイミング**: 出現条件合致の「2分前」および「開始直後」。
  - **環境**: パソコン（デスクトップ通知）、スマホ（ブラウザ起動中のリンクシェル音）。

## 📑 モブリスト：各表記と進行度

各項目には、現在の出現状況を示す各種情報が表示されます。

- **時間と％**
  - **RESPAWNING**: 最短時間までの**残り**時間
  - **POP WINDOW**: 最大時間までの**残り**時間
  - **TIME OVER**: 最大時間からの**超過**時間
  - **特殊条件のSモブ**: 次回条件までの**残り**時間。期間中は**残り**時間
  - 経過％
- **REPORTボタン (⚔)**  
  討伐報告用ボタン。認証済みユーザーのみ操作可能。
- **プログレスバー(%)**  
  最短時刻を経過するとバーが進行し、最大時刻に向かってゲージが伸びていきます。
- **特殊な出現条件のSモブ**  
  時間表示が**黄色**のものは、特殊条件が付いたSモブの出現時刻までの残り時間です。  
  リストが白く発光している場合は、特殊条件が満たされ**現在、出現の可能性がある**状態です。
- **📍(モブリスト)**  
  未確認の候補地の残数が「📍@3」のようにカウントされます。  
  残り1箇所に特定されると「📍14番」のように地点番号が表示されます。

## 🪪 モブカード：情報の補足と座標埋め

モブリストを選択した際に表示される詳細パネル（モブカード）の機能です。

- **共有メモ (memo)**  
  モブごとに最大30文字の投稿ができ、全ユーザーに即時同期されます。
- **出現候補地の調査（座標埋め）**  
  Sモブの出現候補地を調査した結果を記録・共有できます。  
- **操作方法**  
  パソコン: **左クリック1回**でチェック切り替え（右クリックで拡大鏡が使えます）。  
  スマホ　: **1秒以内の2連続タップ**でチェック切り替え。

## 🕒 討伐報告のルールと仕様

REPORT(⚔)から行える報告機能の仕様です。

[**報告の方法**]  

- **Aランク**  
  現在時刻で**即時報告**されます。
- **S/Fランク**  
  報告フォームが開きます。正確な討伐時刻を入力してください。  
  
[**報告の制限と修正**]  

- **時間の整合性**
  最短日時より**5分以上早い**、または現在時刻より**10分以上遅い**の時刻は報告できません。
- **修正**
  誤った報告を修正する場合は、報告フォームを開き、正しい日時を入力して「**修正する**」に☑を入れて送信してください。
